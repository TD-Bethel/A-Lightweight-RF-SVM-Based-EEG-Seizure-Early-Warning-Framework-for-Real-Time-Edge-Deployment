# NeuroWatch Project

> This README is auto-generated by `generate_readme.py`.
> Last generated: 2026-04-29 18:53:21

NeuroWatch is a real-time EEG seizure detection and monitoring system. It uses a hybrid SVM + Random Forest ensemble trained on either the Bonn University or Mendeley EEG dataset to classify brain states as Normal, Pre-Seizure, or Seizure. The system includes a clinician dashboard, a mobile patient UI, SMS alerting, Raspberry Pi hardware support, and optional ngrok remote access.

## Project Structure

- `src/` — application code (monitor engine, dashboards, patient registry, notifier, metrics pipeline)
- `scripts/` — utility scripts (training, prediction helper, dataset scanner, README generator)
- `models/` — trained artifacts and training history
- Root `.py` files — compatibility launchers so existing commands still work

## How to Run

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. (Optional) Configure Twilio SMS placeholders in `.env`.

3. Train a model (choose one dataset):

```bash
# Mendeley dataset (recommended — 247 features, 19 channels)
python train_mendeley.py

# Bonn University dataset (13 features, single channel)
python scripts/train_and_export.py --data "data/Bonn Univeristy Dataset"
```

4. Start the monitoring engine and dashboards:

```bash
# Terminal 1 — live monitoring engine
python src/main_pi_bios_v15.py

# Terminal 2 — clinician dashboard
streamlit run dashboard_v2.py

# Terminal 3 — patient mobile UI (open on phone via ngrok or local IP)
streamlit run src/patient_mobile_ui.py --server.port 8502
```

## What This Project Does

- Detects EEG states as `Normal`, `Pre-Seizure`, or `Seizure`
- Uses a hybrid `SVM + Random Forest` model
- Monitors one live patient and can simulate demo patients for the dashboard
- Writes JSON outputs for real-time UI updates
- Supports optional Raspberry Pi GPIO, LCD, buzzer, and Twilio SMS alerts
