STEP 1 — FLASH THE RASPBERRY PI OS
────────────────────────────────────
  1. Download Raspberry Pi Imager from:
     https://www.raspberrypi.com/software/

  2. Open Raspberry Pi Imager:
     - Device:    Raspberry Pi 3
     - OS:        Raspberry Pi OS Lite (64-bit)
     - Storage:   Your SD card

  3. Click the GEAR icon (settings) before flashing and fill in:
     - Hostname:        theberatsatsipi
     - Enable SSH:      YES (use password authentication)
     - Username:        theberatsatsipi
     - Password:        choose one and WRITE IT DOWN
     - Wi-Fi SSID:      your Wi-Fi name
     - Wi-Fi Password:  your Wi-Fi password
     - Wi-Fi Country:   your country code (e.g. BW for Botswana)

  4. Click SAVE then WRITE. Wait for it to finish.

  IMPORTANT: Make sure username matches hostname (theberatsatsipi) or you
  will get "Permission denied" when trying to SSH.

STEP 2 — ENABLE SSH IF IT IS BLOCKED
──────────────────────────────────────
  If SSH keeps saying "Permission denied" after flashing:
  1. Connect a monitor and keyboard to the Pi
  2. Log in and run:
       sudo nano /etc/ssh/sshd_config
  3. Find: PasswordAuthentication no
     Change to: PasswordAuthentication yes
  4. Save with Ctrl+X → Y → Enter
  5. Run: sudo service ssh restart

STEP 4 — EXPAND SWAP SPACE (IMPORTANT FOR PI 3 — ONLY 1GB RAM)
────────────────────────────────────────────────────────────────
  First install dphys-swapfile (may not be installed by default):

    sudo apt install dphys-swapfile -y

  Then run these commands one at a time:

    sudo dphys-swapfile swapoff
    sudo sed -i 's/CONF_SWAPSIZE=100/CONF_SWAPSIZE=1024/' /etc/dphys-swapfile
    sudo dphys-swapfile setup
    sudo dphys-swapfile swapon

  Verify it worked:

    free -h

  You should see "Swap: 1.0G" or higher in the output.
  This gives the Pi extra virtual memory so it does not crash.

STEP 8 — INSTALL NGROK
────────────────────────
    curl -sSL https://ngrok-agent.s3.amazonaws.com/ngrok.asc \
      | sudo tee /etc/apt/trusted.gpg.d/ngrok.asc >/dev/null

    echo "deb https://ngrok-agent.s3.amazonaws.com buster main" \
      | sudo tee /etc/apt/sources.list.d/ngrok.list

    sudo apt update && sudo apt install ngrok -y

  Now add your ngrok authtoken.
  Get it from: https://dashboard.ngrok.com/get-started/your-authtoken

    ngrok config add-authtoken PASTE_YOUR_TOKEN_HERE

  NOTE: You can skip this step and come back to it later.
  The dashboards will still work on the local network without ngrok.

STEP 11 — CREATE THE STARTUP SCRIPT
─────────────────────────────────────
    cat > ~/start_neurowatch.sh << 'EOF'
#!/bin/bash
source ~/neurowatch_env/bin/activate
cd ~/NeuroWatch_Project

# Window 0: monitoring engine
tmux new-session -d -s neurowatch -n engine
tmux send-keys -t neurowatch:engine \
  "python src/main_pi_bios_v15.py --models models/MODELS_MENDELEY" Enter

# Window 1: clinician dashboard (port 8501)
tmux new-window -t neurowatch -n dashboard
tmux send-keys -t neurowatch:dashboard \
  "streamlit run dashboard_v2.py --server.port 8501 --server.address 0.0.0.0 --server.headless true --server.enableCORS false --server.enableXsrfProtection false" Enter

# Window 2: patient mobile UI (port 8502)
tmux new-window -t neurowatch -n patient
tmux send-keys -t neurowatch:patient \
  "streamlit run src/patient_mobile_ui.py --server.port 8502 --server.address 0.0.0.0 --server.headless true --server.enableCORS false --server.enableXsrfProtection false" Enter

# Window 3: ngrok tunnels (makes both dashboards accessible externally)
tmux new-window -t neurowatch -n ngrok
sleep 5
tmux send-keys -t neurowatch:ngrok "ngrok start --all" Enter

echo ""
echo "  NeuroWatch is running."
echo "  Clinician dashboard : http://10.36.112.54:8501"
echo "  Patient UI          : http://10.36.112.54:8502"
echo "  To see ngrok URLs   : tmux attach -t neurowatch  (Ctrl+B then 3)"
echo "  Switch windows      : Ctrl+B then 0 / 1 / 2 / 3"
echo "  Detach (keep running): Ctrl+B then D"
EOF

    chmod +x ~/start_neurowatch.sh

================================================================================
  TROUBLESHOOTING
================================================================================

  "ssh: Could not resolve hostname theberatsatsipi.local"
  → Use the IP address instead: ssh theberatsatsipi@10.36.112.54
  → If IP changed, connect monitor to Pi and run: hostname -I

  "Permission denied" when SSHing
  → Make sure username is theberatsatsipi (not pi)
  → Check password authentication is enabled:
    sudo nano /etc/ssh/sshd_config
    Set: PasswordAuthentication yes
    Then: sudo service ssh restart

  "dphys-swapfile: command not found"
  → Run: sudo apt install dphys-swapfile -y

  "pip install fails with no space"
  → SD card is full. Use a larger card (32GB recommended).
  → Check space: df -h /

  "streamlit: command not found"
  → You forgot to activate the venv. Run:
    source ~/neurowatch_env/bin/activate

  "Failed to fetch dynamically imported module" errors in dashboard
  → Add these flags to your streamlit command:
    --server.enableCORS false --server.enableXsrfProtection false

  "ngrok tunnel error"
  → Check your authtoken: ngrok config check
  → Re-add it: ngrok config add-authtoken YOUR_TOKEN
  → Get token from: https://dashboard.ngrok.com/get-started/your-authtoken

  Pi freezes / runs out of memory
  → Make sure you did Step 4 (swap space).
  → Reduce streamlit memory: add --server.maxUploadSize 1 to streamlit commands.
